# Two-Stage Miller-Compensated OTA (TSMC 180nm)

Course project at IIT Guwahati (Apr–May 2025): a two-stage operational transconductance amplifier for low-power analog signal chains, designed and simulated in LTspice.

## Results

| Parameter | Value |
|---|---|
| Technology | TSMC 180nm |
| Supply | 1.8 V |
| Load | 10 pF |
| Open-loop gain | 64.28 dB |
| Phase margin | 61° |
| Unity-gain bandwidth | 15 MHz |
| Slew rate | 38.68 V/µs |
| Power | 526 µW |
| Closed-loop gain | 2 |

## Files

- `Draft2.asc` — LTspice schematic. Open it in LTspice (with the TSMC 180nm models) to run the AC, transient and slew simulations.
